# Example crop management practices for miniSTICS

Example crop management parameters used for running the miniSTICS crop
model.

## Usage

``` r
practices_example
```

## Format

A named list with 5 elements:

- sowing_year:

  Year of simulation (YYYY)

- doy_sowing:

  Sowing date as day of year

- doy_stop_sim:

  End date of simulation as day of year. Values up to 730 allow
  simulations over two years.

- zrac0:

  Initial planting depth (cm)

- density:

  Plant density (plants m-2)

## Source

Example dataset distributed with the miniSTICS package.
