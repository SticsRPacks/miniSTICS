# Example weather station for miniSTICS

Example geographical information of the weather station used with the
miniSTICS demonstration dataset.

## Usage

``` r
weather_station_example
```

## Format

A named list with 2 elements:

- lat:

  Latitude of the weather station (decimal degrees)

- z:

  Elevation of the weather station above sea level (m)

## Source

Example dataset distributed with the miniSTICS package.
